# 深空航行 (Deep Space Voyage)

    “深空还在扩张，而你的星图永远缺了最后一块拼图。”

《深空航行》是一款基于 Web 的科幻硬核 Roguelike 资源管理与叙事游戏。你将指挥“远征号”飞船，在资源匮乏、物理法则崩塌的深空中航行。每一个决策都关乎生死，每一公里都在逼近虚空的终点。

## 🌌 游戏背景
在遥远的未来，人类向深空发起了最后的探索。随着航行距离突破 200,000 公里，物理常数开始失效，一个名为 OMEGA (欧米伽) 的虚空演化终点出现在航线末端。

你是选择为了真理彻底坠入虚空，还是在最后一刻点燃推进器，逃向那不可知的回头路？

---

## 🚀 核心机制
资源微操：严格管理氧气、电力、密封剂和载员。资源不仅是生存的保障，更是战斗的筹码。

距离驱动：随着航行距离增加，敌对生物质的威胁等级将呈指数级上升。

时间锚点：利用不稳定的时空技术，在关键节点建立锚点。死亡并非终点，而是另一次时间线的尝试。

多维结局 (三分支系统)：

[ 胜利 ]：击败 OMEGA，代价是成为深空的一部分。

[ 战败 ]：飞船塌陷在黑暗中，成为后方观察到的最后一道光。

[ 撤离 ]：在推力已达极限的状态下强行跳跃，留下永恒跳动的求救信标。

---

## 🛠️ 技术实现
纯原生驱动：基于 Vanilla JavaScript 构建，无第三方框架依赖，追求极简与流畅。

状态隔离渲染：自定义 renderAll 劫持逻辑，实现战斗 UI 与沉浸式结局演播的无缝切换。

异步叙事系统：基于 async/await 的逐行文本渲染技术，全白单色 Monospace 风格，营造冷酷的终端指令感。

## 📦 快速开始
由于本项目使用了 ES Modules，直接双击 index.html 会因浏览器安全策略导致无法加载脚本。请使用以下方式运行：

### 方法 1：使用 VS Code (推荐)
在 VS Code 中打开项目文件夹。

安装扩展 Live Server。

点击右下角的 "Go Live" 按钮，游戏将在浏览器中自动开启。

### 方法 2：使用 Python
在项目根目录下运行：
```bash
python -m http.server 8000
```

然后在浏览器访问 http://localhost:8000。

方法 3：使用 Node.js
```bash
npx serve .
```
